# Pet Adoption System — Agent Prompt

- Java 21, Spring Boot 3.x, Spring Cloud (Eureka, Gateway)
- Keycloak (OAuth 2.0 / JWT) for authentication

- Docker Compose for local environment
- Lombok, Spring Data JPA, Spring Security
